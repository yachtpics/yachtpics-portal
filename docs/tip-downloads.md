# Tip: Download All now saves straight to a folder

_Draft for Charlie to review before sending — Oct 30, 2026._

**Downloading your photos just got simpler.** In Chrome or Edge on a computer, Download All now puts the photos straight into a folder you choose — named for the boat, numbered in listing order, with nothing to unzip. Your computer asks you to pick a folder and to let the Portal save there; Downloads is fine. Web & MLS (2048px) is the default and the right size for listing sites and email; choose Full resolution only for print, and click "or as a .zip" if you'd rather have a single file to send.
